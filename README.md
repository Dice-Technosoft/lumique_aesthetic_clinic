# Lumique Aesthetic Clinic

A luxury dermatology and aesthetic clinic website built with static HTML5, CSS3, and Vanilla JavaScript.

## Getting Started

Serve directly via Apache / XAMPP:
- Path: `http://localhost/lumique_aesthetic_clinic-main/`
- Or open `index.html` directly in any modern web browser.

## Pages
- `index.html` — Home
- `about.html` — About Clinic & Doctor Profile
- `treatments.html` — Treatments Catalog
- `treatment-detail.html` — Treatment Details & FAQs
- `blog.html` — Educational Articles & Search
- `blog-post.html` — Article Reader
- `contact.html` — Clinic Contact & Appointment Booking
- `admin.html` — Admin Management Portal
